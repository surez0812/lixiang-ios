# 数据来源与准确性口径

## 历法/黄历数据

- **唯一内核**：[`6tail/lunar-swift`](https://github.com/6tail/lunar-swift) 1.1.9（MIT）。公历/农历、节气（含交节时刻）、节日、宜忌、冲煞、吉神凶煞、彭祖百忌、方位、胎神、建除十二神、黄道黑道、星宿、纳音、物候、法定节假日+调休。
- **不宣称「最准/权威」**：传统黄历的宜忌/神煞存在流派差异，产品文案统一为「依 6tail lunar 数据（传统历法算法）」并提供流派说明；可硬对拍的只有节气/农历/假期。
- 春节/除夕/闰月等：除夕按「农历腊月最后一天」计算（可能是廿九，如 2026/2027/2028 均为腊月廿九）；闰月三态与 `dayFallback` 见内部数据模型文档。

## 权威对拍来源（QA/发布前）

| 数据 | 来源 | 频率 |
|---|---|---|
| 节气时刻 / 农历对照 | 紫金山天文台《中国天文年历》、香港天文台年历、香港天文学会《天文年曆》 | 发布前 + 每年补次年 |
| 法定节假日/调休 | 国务院办公厅年度通知（`gov.cn`） | 每年 11 月通知发布后更新 |
| 实现一致性 | `lunar-python` 同版本（仅本地对拍，不随包） | 升级上游时 |

## 节假日数据更新

- 上游仅在每年 11 月随库发版加入次年假期；本项目保留**自有 HolidayData 覆盖层**（随包 JSON + 可选远程更新），以产品自有数据为准并与上游交叉校验。
- 上游当前版本已含 2026/2027 数据，且与 gov.cn 原文逐条一致（研究阶段实测，见内部交接证据）。
