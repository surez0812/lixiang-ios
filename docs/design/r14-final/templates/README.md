# 岁时网页模板

festival-article.template.html是供主站admin渲染器使用的带占位符母版；不是直接发布的页面。schema和sample JSON定义编辑字段。webpages/下是可直接预览的两篇内容样本，便于多设备审稿。

原生负责日期/分类/解锁/导航/分享/网络状态；WKWebView只负责文章图文与来源。正式远程链接尚未接入，样本来源待编辑补齐，禁止把它当成已上线内容。

模板无JavaScript、无系统权限请求、无第二套App导航。原生传入data-theme及字体缩放，WKWebView负责单一正文滚动；原生外层不再嵌套一个正文滚动区。宽屏原生摘要左列＋网页右列，窄屏摘要在上、正文在下；内容最大阅读宽度880px。
