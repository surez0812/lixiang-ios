# 历象 R11 · 日期型黄历与日/时罗盘

本轮覆盖 R10 的“仅日方位”“今日罗盘”规则，其他已确认布局继续保留。当前交付为设计/独立原型，不改 App、不构建、不提审。

## 罗盘入口与页面

黄历主卡右上角入口改为“罗盘”：暖纸色胶囊、21pt线性罗盘图标、清晰文字、最少44pt高，和返回按钮分别占据左右操作位置。入口为真实 anchor，并携带当前黄历日期。主卡装饰图层 pointer-events:none；按钮独立 z-index:8，明确 pointer-events:auto，避免视觉装饰拦截点击。焦点框可见。

罗盘独立页面保留14种设备/主题布局：普通iPhone竖屏浅/深、iPad横竖浅/深、Duo Close Portrait/Close Landscape/Tent/Open Portrait/Open Landscape/Tabletop/Splitview左右。每种交付日方位和时方位，28张罗盘PNG。

日/时为同组分段按钮，点击高度至少44pt。日方位显示所选日；时方位展示十二时辰选择器（时支+干支），选项改变后五吉神标记、方向图例和煞方同步更新。默认时方位示例为巳时，12种时辰均可选。两种维度共用固定北向底盘，保留“上方为正北”的方向说明。横屏采用控制/罗盘左右结构，分别滚动；竖屏连续阅读。

## 日期型黄历

页面标题统一“黄历”；“宜忌”“历法说明”不再固定使用今日。岁时使用“当日岁时”，强调当前所选日。首页当天Hero与今日黄历摘要仍按当天表达，不全App替换。

主卡底部放“‹ 前一天”“后一天 ›”两个等宽入口，至少44pt。基于当前 YYYY-MM-DD 日期加减一天，使用UTC中午计算避免时区偏移；支持跨月/跨年/闰年。跳转保留设备模式，白话偏好继续在本机保留。进入罗盘再返回时保留相同日期。

本轮是布局/交互原型：日期标题、日期路由、岁时匹配更新；其余黄历字段和日/时方位以 calendar-fixture.json 的2026-11-12固定样本验证。此前原型的样本提示保留。正式App接入时，日期更改必须重新读取对应日期的全部黄历、十二时辰和罗盘数据，禁止只改标题；没有将本轮原型宣称为完整跨日历法引擎。

## 白话两态

开启：宜忌逐项解释，历法说明逐项展开。关闭：宜/忌两项换行摘要；历法说明为紧凑名称/值行，保留值神、冲煞、纳音、建除、彭祖、胎神、星宿、吉神/凶神等原始数据，隐藏白话长段落、缩小行间距。开关可双向恢复。横屏仍保持左右满高、各自滚动。

## 交付与验证

216张PNG与对应HTML（含28张罗盘日/时稿、前后日专项示意），索引集中在index.html。PNG由离线HTML局部排版、原图和矢量合成，不是浏览器或模拟器截图。

286项源结构/JavaScript语法检查，14模式的日期切换与全部12时辰联动脚本执行检查、文件链接/导出尺寸/导航及抽签按钮边界检查。按钮图层和折叠规则通过源结构核对，实际浏览器命中测试、真实滚动、native safe area未在本chat运行。此前协作方的R10浏览器报告只属于R10，不自动当作R11验收。

冻结抽签素材、1450ms核心和定稿视频保持不变。build12未改、不提审。
