# 历象 R10 布局修订

本轮规范优先于 R9 冲突项。保留 D1 纸色内容、Liquid Glass 浮动控制、五 Tab 与所有设备统一首页。只交设计与原型；不改 App，不构建、不提审。

## 本轮布局

岁时筛选为单条横向滚动带，标签不换行；每项点击高度至少 44pt。iPhone 首屏显示主要类别，剩余类别横滑可达。岁时详情去掉夸张标题留白，采用分类、30pt 标题、短引导和日期/操作组成的紧凑原生头部；下方 Web 正文区域使用剩余空间，远程模板边界不变。

首页“每日一签/今日天气”居中排版、等高卡片。横屏左列布局为 Hero 弹性区域 + 16pt 间距 + 156pt 工具行；卡片按 border-box 计算，禁止工具行超出内容视口。Hero 随可用高度分配插画区，保留插画到纸色渐隐。其他首页顺序不变。

iPad 横屏每日一句/分享页为左右两列：左侧经文与解释，右侧分享卡、二维码与分享/保存按钮，两列可独立滚动。

黄历主卡同时包含日期、历法纪年以及当日岁时。相同的黄帝/道历年份合并，佛历保留；当日岁时精确日期匹配，无匹配不留空位，有多个项目逐条列出。卡片不设置固定高度，内容自然扩展。

主卡右上角设置“今日罗盘 ›”入口，打开独立 compass 页面，仅显示所选日的方位与图例，移除日/时切换，舍弃时方位。所选日期从黄历传入罗盘，返回黄历时保留。原型除匹配列表和日期参数外仍采用 2026-11-12 样本值，不能用于其他日期的真实方位判断。

iPad landscape、Duo 横屏黄历：外层视口固定为可用内容高度，采用两列 grid、minmax(0,1fr) 行，两列 height:100%、min-height:0、独立纵向滚动。左列主卡/宜忌/历法解释；右列完整十二时辰。十二时辰内部列表取消额外高度上限，滚动归右列处理。整屏内容不一起滚动；底部/侧边全局导航保持浮动固定。

Duo Close Portrait 纪念日列表：“记下一个日子”为 48pt 按钮，与第一张纪念日卡明确间隔 20pt，按钮文字垂直居中。

## 交付与边界

14 种画布，11 类页面（增加独立日罗盘），共 200 张 PNG、对应 HTML、逐条清单与接入说明。页面索引见 index.html；图片尺寸与离线合成证据见 R10-RENDER-PROVENANCE.json。

PNG 由 HTML 局部排版和原图离线合成，不是浏览器或模拟器截图。源文件检查可证明滚动结构、链接和样本规则，不等同真实浏览器滚动或 native SwiftUI 验证。开发仍需验证 iPad/Duo 实际 safe area、动态字体与原生滚动。已定稿抽签素材和动画核心不变，build12 未改。

原始意见和旧版本规范留存于 history/ 与 R9 文件，冲突时以本文件及 R10-COVERAGE.md 为准。
