# R11 黄历/罗盘接入约定

以 ../R11-DESIGN-SPEC.md 为准，覆盖R10的仅日方位要求。

- 主卡罗盘入口44pt以上，装饰图忽略hit testing；真实导航操作携带selectedDate。
- 罗盘支持day与hour两态，hour支持十二时辰。日历数据源同时提供该日与各时辰方向，更新标记、图例和煞方。
- 前后一天只改变selectedDate；随后必须重新读取该日所有字段，不能只替换日期标题。原型仍使用单日样本，不可直接作为生产数据逻辑。
- 白话关闭时，历法说明为名称/值紧凑行，开启恢复解释；保留前轮宜忌收拢。
- 所有设备的罗盘日/时两态已交，横屏满高分列、独立滚动沿用。
