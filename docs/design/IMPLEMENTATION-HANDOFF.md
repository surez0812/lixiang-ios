- 罗盘是独立页，保留日/时切换、十二时辰、五吉神方向及煞方；不得回退 R10 仅日方位。普通 iPhone/iPad 右上文字玻璃按钮“值神罗盘”，返回左上；Duo保留相邻侧栏控件关系。
