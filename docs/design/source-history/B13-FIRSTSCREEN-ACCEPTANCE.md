# build13 单日详情验收标准（Sure 拍板 2026-11-12，替代旧 20 项硬指标）

- 适用：`B13-Lixiang-app-density*` 后续版本；375×812 为主，iPad 单列限宽
- **核心原则：风格一致性优先（D1 语言：暖纸/朱印/印章/留白/层级，与 Hero 统一），不允许密网格/变味**

## 验收项（QA 逐项记录）
1. **风格统一**：暖纸底/朱印/印章/留白/字号层级与 Hero 一致；无密网格感/无「仪表盘」感
2. **适度密度**：首屏有完整核心感即可，允许 **1–1.2 屏自然滚动**；不硬塞全部
3. **无重复**：宜忌/值神/罗盘/术语等每项仅一处；无重复 panel
4. **无卡顿**：滚动/展开流畅；Instruments 真机/QA 机证据（sim 受限可标 NOTRUN）
5. **白话 8 域可点**：值神/吉神/凶煞/建除/彭祖/星宿/纳音/胎神（+冲煞）均有「白」入口，点击内联/sheet 显示 zh/en（v2 三段后升级）
6. **首屏核心观感完整**：日期 + 农历（大农历日）+ 宜忌 + 值神 + 冲煞 + 星宿 + 方位（财福喜阳贵）+ 罗盘 + 吉神/凶煞 + 时辰——**在首屏或首屏+少量自然滚动内完整呈现**（不要求全部挤进一屏）
7. **次要可折叠**：彭祖百忌/更多术语/民俗未来 10 天/天气 → 折叠默认收（可 header 可见）
8. 亮暗无 cut；对比 ≥4.5；无占位/假分类
